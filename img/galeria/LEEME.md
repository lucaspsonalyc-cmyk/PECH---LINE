# Fotos de la galería

Sube aquí las 12 fotos de la galería con estos nombres exactos:

`01.jpg`, `02.jpg`, … `12.jpg`

- Mientras falte una foto, la web muestra el recuadro "📷 Imagen pendiente".
- El título y el texto de cada foto se editan en `index.html`, en la lista `const galeria = [ … ]`.
- Recomendado: fotos cuadradas o casi cuadradas, de 1200 px de ancho como máximo, para que carguen rápido.
